# 🔄 Przemienniki

Prosta i wygodna strona internetowa z różnymi przemiennikami i konwerterami.

## 📋 Opis

**Przemienniki** to strona, która pozwala szybko przeliczać wartości pomiędzy różnymi jednostkami.

Strona została zaprojektowana tak, aby korzystanie z przemienników było proste, szybkie i intuicyjne.

## ✨ Funkcje

- 📏 Przemiennik długości
- ⚖️ Przemiennik masy
- 🌡️ Przemiennik temperatury
- ⏱️ Przemiennik czasu
- 🚗 Przemiennik prędkości
- 📐 Przemiennik powierzchni
- 🧊 Przemiennik objętości
- 💾 Przemiennik danych
- 💱 Przelicznik walut
- 📱 Responsywny interfejs

## 🛠️ Technologie

Projekt został wykonany przy użyciu:

- HTML
- CSS
- JavaScript

## 🚀 Uruchomienie

Aby uruchomić stronę lokalnie:

1. Pobierz repozytorium.
2. Otwórz plik `index.html`.
3. Uruchom go w wybranej przeglądarce.
